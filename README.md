# Buffalo TeraStation NAS
Custom NAS integration for Buffalo Terrastation NAS

## Tested Devices

This integration has been tested on the following Buffalo NAS devices:

- Buffalo TeraStation **TS3410D**
  - Firmware: 5.x
  - RAID6
  - 4× SATA disks

Other TeraStation models using the same web UI and JSON‑RPC API may work but are untested.
